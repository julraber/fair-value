Zukunftskurs = EPS Zukunft × jeweiliges faires KGV
Fair Value heute = Zukunftskurs ÷ (1 + Zielrendite)Jahre

Die Unterbewertung wird als Abstand des aktuellen Kurses zum Fair Value berechnet: (Fair Value − aktueller Kurs) ÷ Fair Value.
